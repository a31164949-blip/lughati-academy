# تعليق الحساب والمزايا

- تعليق المزايا الإضافية تلقائيًا عند مرور 14 يومًا دون واجب منجز أو قراءة مرسلة غير مرفوضة. الدخول وحده والنقاط المهداة لا يعدّان مشاركة.
- يحسب القرار من سجلات الطلاب الحالية عند الدخول أو طلب ميزة محمية، ولا يحتاج إلى مهمة مجدولة أو كتابة دورية في قاعدة البيانات.
- الحسابات الجديدة لها مهلة 14 يومًا من الإنشاء أو أول دخول. إذا كانت تواريخ الإنشاء والدخول مفقودة، لا يعلّق الحساب تلقائيًا دون دليل.
- تبقى الواجبات والقراءة والخطة ومواد التأسيس متاحة في التعليق التلقائي. واجهة النادي والتحديات الخاصة وتحليل الخط وتعديل الصورة وعجلة المكافآت تخضع للتعليق.
- من لوحة المعلم ← إدارة الطلاب ← تعليق الحساب والمزايا: تعليق المزايا، تعليق الحساب كاملًا مؤقتًا، أو إعادة التفعيل مع مهلة أسبوعين. المدة 3 أو 7 أو 14 أو 30 يومًا، أو حتى يعيد المعلم التفعيل.
- التعليق الكامل يمنع عرض خدمات الطالب والتحقق من رمزه في واجهات الخادم المحمية، مع إبقاء نقطة قراءة حالة الحساب متاحة لعرض التنبيه وبطاقة «تواصل مع معلمي» فقط للدعم والاستفسار. رسائل الطالب وردود المعلم تظل متاحة أثناء التجميد.
- ليس التنبيه إحالة فعلية إلى الموجّه الطلابي؛ الإحالة إجراء تربوي ينفذه المعلم بالتنسيق مع الأسرة.
- القراءة قيد المراجعة تحتسب مشاركة حتى لا يتأثر الطالب بتأخر اعتماد المعلم. الواجبات المعادة أو المرفوضة لا تحتسب. قرار التعليق اليدوي له الأولوية على المشاركة الجديدة.
- نتائج التفاعل مخزنة مؤقتًا لمدة خمس دقائق، مع إبطالها بعد تسليم الواجب أو القراءة وإعادة التفعيل. تغييرات رفض المشاركات من المعلم تظهر خلال خمس دقائق كحد أقصى.

## التحقق والنشر

التحقق: `node scripts/test-student-access.cjs`، و`npx tsc --noEmit`، و`npm run build`.

النشر يتضمن كود Next.js وقواعد Firestore المعدّلة في `firestore.rules`. نشر Vercel وحده لا ينشر قواعد Firestore. يجب نشر القواعد بواسطة حساب Firebase مخوّل قبل إعلان اكتمال حماية الطلبات المباشرة إلى Firestore.

يلزم اختبار بحساب المعلم وطالب في البيئة المنشورة: التعليق اليدوي للمزايا، بقاء الواجبات متاحة، تعليق الحساب الكامل، ظهور تنبيه الأسرة، انتهاء المدة، وإعادة التفعيل. لم تتوفر جلسة متصفح موثقة أو بيانات Firebase Admin محلية لإجراء هذا الاختبار هنا.

- يتابع حاجز الدخول تغيّر قرار المعلم أثناء فتح الصفحة، ويعيد التحقق عند العودة إلى التطبيق. أثناء التجميد الكامل يتحقق من إعادة التفعيل كل دقيقة عندما تكون الصفحة ظاهرة.
- زر «تجميد الحساب بالكامل — تواصل مع معلمي فقط» يغلق جميع الخدمات. زر «تعليق الإضافات فقط — تبقى الواجبات والقراءة» قرار مختلف ولا يجمّد الحساب كاملًا.
